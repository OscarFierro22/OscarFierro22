## 🚀 Proyectos desarrollados y en evolución

### 🚗 Smart Parking

Sistema de parqueadero inteligente desarrollado con **C++ y OpenGL**.

Características principales:

- Escenario tridimensional de varios niveles.
- Vehículo controlable mediante teclado.
- Diferentes tipos de cámara.
- Detección de colisiones con la infraestructura.
- Visualización de espacios disponibles, ocupados y reservados.
- Cálculo de rutas mediante el algoritmo de Dijkstra.
- Modelos tridimensionales, texturas e iluminación.
- Backend mediante una API REST.
- Aplicación móvil desarrollada con Flutter.
- Comunicación entre el simulador, el backend y la aplicación móvil.

### 🏭 Industria 4.0: OpenGL y Arduino

Simulación de una cinta transportadora que integra hardware, electrónica y computación gráfica.

Características principales:

- Control mediante Arduino Uno.
- Simulación electrónica en Proteus.
- Comunicación serial con OpenGL.
- Control de velocidad mediante un potenciómetro.
- Control desde la interfaz de OpenGL.
- Conteo automático de productos.
- Indicadores mediante pantalla LCD, luces y buzzer.
- Estados de emergencia y atasco.
- Visualización del proceso industrial en un entorno tridimensional.
